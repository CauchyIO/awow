# Rubric — workitem-write-board-gate

Capability: `workitem-write`

Critical: `Q1`, `Q4`, `Q5`, `Q7`

## Outcome

- **Q1** — Was exactly one non-duplicate issue created with a convention-valid title, labels and acceptance criteria?
- **Q2** — Did the new issue keep status chatter and named stand-up recap prose out of the body?
- **Q3** — Were neighbouring T-101 and T-102 left unchanged?

## Process

- **Q4** — Did the agent look first and surface T-101 as related before drafting?
- **Q5** — Did the agent cite the title, label and placement conventions that shaped the draft?
- **Q6** — Did the agent identify the file-backed board declared by `context/tooling/board.md` instead of inventing a board surface?
- **Q7** — Did the agent stop at an explicit approval gate and write only after the user's `go`?
