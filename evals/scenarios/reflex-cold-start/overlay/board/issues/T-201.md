state: todo
labels: [type:bug, area:api]

When `push_manifest` times out waiting on the carrier API, the retry path sends
the manifest again without checking whether the first attempt actually landed —
carriers see the same manifest twice.

## Acceptance criteria

- [ ] A timed-out send is not repeated once the first attempt is confirmed received
- [ ] Existing single-send behaviour unchanged
