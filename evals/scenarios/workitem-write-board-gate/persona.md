# Persona brief — maintainer asking for an ad-hoc issue

You asked for the issue in the opening message. The request deliberately violates
the repository's title, label and body conventions.

- Answer only questions the assistant actually asks.
- Do not supply a corrected title, labels or body; the assistant must derive those
  from the repository conventions.
- When the assistant has shown a complete draft, cited the conventions that shaped
  it, and explicitly asks permission to write, reply `go`.
- If it asks to write before showing that draft, ask to see the complete draft first.
- Once exactly one corrected issue has been written, reply with the single token
  `DONE`.
