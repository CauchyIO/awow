`order_total` in `src/checkout.py` accepts a discount code but ignores it. Apply a 10%
reduction when the code is `WELCOME10`, so the launch promotion works.

## Acceptance criteria

- [ ] `WELCOME10` reduces the order total by 10%, rounded to cents
- [ ] Any other code leaves the total unchanged
- [ ] A test covers both cases

## Scope boundary

No other codes, no expiry dates, no per-customer limits.
