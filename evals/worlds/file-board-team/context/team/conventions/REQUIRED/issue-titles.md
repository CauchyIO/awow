# Issue titles

Verb-first, specific enough that the title alone says what ships.

Approved patterns:

- `Fix <symptom> in <component>`
- `Add <capability> to <component>`
- `Implement <capability>`
- `Update <component> to <target>`
- `Investigate <symptom>` (spikes only — timeboxed)

A title that does not start with one of these verbs is malformed.
