# awow setup and ways-of-working workshop — meeting archetype

## When this lens applies

Apply this lens when a team discusses its mission, how work flows, recurring
meetings, working agreements, ownership, output placement, scope boundaries,
or choices needed to configure awow.

## What to extract

- Build a coverage map across mission, board practice, conventions, members,
  style, scope boundaries, recurring meetings, custom meetings, and technical
  configuration.
- Classify each statement as current practice, agreed change, suggestion, or
  unresolved disagreement.
- Compare recurring meetings with the generic archetypes and retain only
  meaningful team differences; fully describe genuinely custom meetings.
- Route the segment to `/setup-awow` for proposal-first synthesis.

## Missing topics worth noting

Leave uncovered setup areas pending. Ask follow-up questions only when a missing
answer blocks safe configuration.

## Common interpretation mistakes

Do not turn one person's recollection into a team rule, resolve disagreement by
majority guess, copy raw transcript text into context, or treat credentials and
tool installation as workshop decisions.
